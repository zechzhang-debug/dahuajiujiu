三角形外角与角平分线

初二上 · 三角形 · 题目 01

内角和外角角平分线

题目

在 △ABC 中，∠A=50°，∠B=60°。把 BC 延长到 D，射线 CE 平分外角 ∠ACD。求直线 CE 与直线 AB 所成的较小角。

题型参考：试题网八年级上册数学同步与期末资源，重新设数整理。

解答

求 C 点内角

∠ACB=180°−50°−60°=70°

求外角并平分

∠ACD=180°−70°=110°
∠ECD=110°÷2=55°

作平行线比较方向

过 C 作 CF∥AB。因为 CD 与 BC 同向，AB 与 BC 所成角为 60°，所以：

∠FCD=60°

求两直线较小夹角

CF∥AB，因此 CE 与 AB 的夹角等于 CE 与 CF 的夹角。

60°−55°=5°
答案：5°。只用了三角形内角和、邻补角、角平分线和平行线，不涉及相似或三角函数。
