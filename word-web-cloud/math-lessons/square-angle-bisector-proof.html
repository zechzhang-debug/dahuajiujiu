正方形辅助线全等三角形角平分线

题原题呈现

如图，点 E 是正方形 ABCD 的边 BC 上一动点，AE ⟂ EG，垂足为 E，∠DCG = 45°。

连接 AG 交 CD 于点 F，连接 EF。

求证：∠CEG = ∠FEG。

💡核心关系拆解

不设未知数，也不计算长度。我们只补两个点：

在 AB 上取 P，使 BP=BE；延长 CD 到 K，使 DK=BE

同一条线段 BE 被“搬”到两个位置，用来制造全等三角形。

第一步：△AEP ≌ △EGC，推出 AE=EG；第二步：△ABE ≌ △ADK，再证 △AEF ≌ △AKF，最后只做角度加减。

拖动 E，观察 P、K、G、F 一起变化。辅助点始终满足 BP=BE、DK=BE。

证完整证明

在 AB 上取一点 P，使 BP=BE，连接 PE。

因为 ABCD 是正方形，所以 AB=BC。从相等的整段中减去相等的小段，得到

AP = AB−BP = BC−BE = CE

又因为 BP⊥BE 且 BP=BE，所以 △PBE 是等腰直角三角形，∠BPE=45°。

因此 ∠APE=180°−45°=135°。而 ∠DCG=45°、DC⊥CE，所以 ∠ECG=135°。

因为 AB⊥BC、AE⊥EG，两个角的两边分别垂直，所以

∠PAE = ∠CEG

比较 △AEP 和 △EGC：

① ∠PAE=∠CEG；② ∠APE=∠ECG=135°；③ AP=CE。

所以由“角边角”可得 △AEP ≌ △EGC，从而

AE = EG

已知 AE⊥EG，因此 △AEG 是等腰直角三角形，故 ∠EAG=45°。又 A、F、G 共线，所以 ∠EAF=45°。

延长 CD 到点 K，使 DK=BE，连接 AK。

在 △ABE 和 △ADK 中：

① AB=AD（正方形的边相等）；② BE=DK（作法）；③ ∠ABE=∠ADK=90°。

所以由“边角边”可得

△ABE ≌ △ADK

于是 AE=AK，并且 ∠BAE=∠DAK。

设 ∠BAE=∠CEG=α。由上一步，∠DAK=α。

因为 ∠BAD=90°，所以 ∠EAD=90°−α，进而

∠EAK = ∠EAD+∠DAK = 90°

又 AE=AK，所以 △EAK 是等腰直角三角形。已知 ∠EAF=45°，因此 AF 正好平分 ∠EAK，即 ∠EAF=∠FAK=45°。

在 △AEF 和 △AKF 中，AE=AK、AF=AF、∠EAF=∠FAK，所以

△AEF ≌ △AKF

从而 ∠AEF=∠AKF。在直角三角形 ADK 中，∠AKF=90°−α，故 ∠AEF=90°−α。

最后，因为 AE⊥EG，所以

∠FEG = 90°−∠AEF = α = ∠CEG
∴ ∠CEG = ∠FEG
结论：EG 平分 ∠CEF

🔑这类题的通用套路

  • 搬相等线段：把 BE 分别搬到 AB、CD 延长线上，主动制造全等条件。
  • 整段减小段：由 AB=BC、BP=BE，马上得到 AP=CE。
  • 垂直角互换：两组角的两边分别垂直时，对应的锐角相等。
  • 45°想到等腰直角：先用全等得到 AE=EG，再结合 AE⊥EG，得到 ∠EAF=45°。
  • 最终只算角：把目标角统一写成 α 或 90°−α，不需要求任何具体长度。
