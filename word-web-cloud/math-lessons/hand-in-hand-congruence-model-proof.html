手拉手全等模型

共顶点、同顶角、对应“手”相连

等腰三角形SAS旋转全等

模型条件与结论

△ABC 与 △ADE 共用顶点 A，且 AB=AC、AD=AE、∠BAC=∠DAE，且 B→C 与 D→E 是绕 A 的同向同角旋转，A、B、D 不共线。连接 BD、CE。证明：
△ABD≌△ACE，从而 BD=CE

连接对应的“手”

完整证明

1. 整理两组腰

已知 AB=AC、AD=AE。

2. 证明夹角也相等

同一次旋转将射线 AB、AD 分别映到 AC、AE，保持两射线的夹角，因此：

∠BAD=∠CAE
3. SAS 全等
△ABD≌△ACE（SAS）

所以对应边 BD=CE，对应角 ∠ABD=∠ACE。

“左手拉左手、右手拉右手”，本质是绕公共顶点的同角旋转。

方法复盘

隐藏夹角从哪里来

已知两个顶角相等，而 △ABD 与 △ACE 需要的是 ∠BAD 与 ∠CAE。题设中的同向旋转同时映射这两条射线，因此夹角相等；不能省略旋转方向条件。

为什么是 SAS

AB=AC、AD=AE 是两组对应边，∠BAD=∠CAE 正好是它们的夹角，因此满足边角边，不是容易误用的边边角。

结论如何迁移

全等后不仅得到 BD=CE，还能得到 ∠ABD=∠ACE。后续题目常利用这组对应角继续证明平行、垂直或新的等腰三角形。

条件检查：两次旋转必须同向

把射线 AB 绕 A 旋转 θ 到 AC 时，射线 AD 也必须按同一方向旋转同一个 θ 到 AE。只有无方向的两个顶角数值相等，不足以保证 BD=CE。若 A、B、D 共线，可直接用旋转保距；使用三角形全等判定时应排除退化情形。

坐标例题与直角拓展

取 A=(0,0)、B=(4,0)、D=(1,2)，把 B、D 同时绕 A 逆时针旋转 90°，分别得到 C、E。求 BD、CE，并判断两直线的关系。
展开解题过程与答案

旋转规则为 (x,y)→(−y,x)，因此 C=(0,4)、E=(−2,1)。

BD²=(4−1)²+(0−2)²=13；CE²=(0+2)²+(4−1)²=13。

BD 的方向向量可取 (−3,2)，CE 的方向向量为 (−2,−3)，内积为 6−6=0；也可直接利用旋转 90° 使对应直线垂直。

BD=CE=√13，BD⊥CE。数值计算用于核对；一般结论来自同一次旋转。

自测：怎样连接对应点

若两个等腰三角形共顶点 A，B→C、D→E 是同向 60° 旋转，且 BD=8，能否直接断言 BE=CD？
展开解题过程与答案

同一次旋转把线段 BD 映到 CE，因此一定有 CE=8。

BE 与 CD 并不是这一次旋转给出的对应线段，不能直接由这些条件推出相等。

只能直接确定 CE=8；先写点的映射，再连接对应点。
